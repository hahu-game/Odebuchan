# 7.4 TurnProcessor.cs (特殊能力: がむしゃらの実装)

## ファイルパス
`Assets/Scripts/Game/TurnProcessor.cs`

## 目的
がむしゃらの効果を実装する

## 実装概要
- ExecuteAction()にがむしゃらの処理を追加
- 元気-40
- 4パターンからランダム選択（各25%）:
  1. たべるの重さ増加×1.2倍
  2. ねむるの元気増加×1.2倍
  3. PlayBuffWeight +15, PlayBuffEnergy +15
  4. MIX: 重さ増加なし、元気増加×0.5、バフ各+15
- ジャンルがNone（ジャンケン判定なし）

## 確認項目
- [ ] がむしゃら実行で元気-40されること
- [ ] 4パターンのいずれかがランダムに選ばれること
- [ ] 各パターンの効果が正しく適用されること
- [ ] ジャンケン判定が行われないこと
