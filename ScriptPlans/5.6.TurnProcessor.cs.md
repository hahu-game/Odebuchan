# 5.6 TurnProcessor.cs (連続使用ペナルティの実装)

## ファイルパス
`Assets/Scripts/Game/TurnProcessor.cs`

## 目的
同じ行動を連続で選択した場合の元気ペナルティを実装する

## 実装内容

### 1. PlayerActionDataへのプロパティ追加

PlayerActionData.csに以下を追加：

```csharp
/// <summary>
/// 前日の午後の行動（連続使用判定用）
/// </summary>
[Networked]
public ActionType LastAfternoonAction { get; set; } = ActionType.Sleep;
```

### 2. TurnProcessorに連続使用判定メソッドを追加

```csharp
/// <summary>
/// 連続使用ペナルティをチェックして適用
/// </summary>
/// <param name="player">プレイヤー</param>
/// <param name="currentAction">現在の行動</param>
/// <param name="previousAction">前の行動</param>
/// <returns>ペナルティが適用された場合true</returns>
private bool CheckConsecutivePenalty(PlayerRef player, ActionType currentAction, ActionType previousAction)
{
    // 連続使用判定
    if (currentAction == previousAction)
    {
        // 元気-20のペナルティ
        var uyopyon = GameManager.Instance.GetUyopyonState(player);
        if (uyopyon != null)
        {
            uyopyon.Energy -= gameParams.ConsecutiveUsePenalty; // 20

            GameFlowManager.Instance.RPC_AddLog(
                $"{uyopyon.OwnerPlayer}の連続使用ペナルティ！ 元気-{gameParams.ConsecutiveUsePenalty}"
            );

            Debug.Log($"[TurnProcessor] {player} 連続使用ペナルティ適用");
            return true;
        }
    }
    return false;
}
```

### 3. ProcessMorning()とProcessAfternoon()での適用

```csharp
/// <summary>
/// 午前の行動を処理
/// </summary>
public void ProcessMorning()
{
    foreach (var kvp in GameManager.Instance.playerActionDataDict)
    {
        PlayerRef player = kvp.Key;
        PlayerActionData actionData = kvp.Value;

        // 前日午後と今日午前が同じかチェック
        CheckConsecutivePenalty(player, actionData.MorningAction.ActionType, actionData.LastAfternoonAction);

        // 行動を実行
        ExecuteAction(player, actionData.MorningAction, true);
    }
}

/// <summary>
/// 午後の行動を処理
/// </summary>
public void ProcessAfternoon()
{
    foreach (var kvp in GameManager.Instance.playerActionDataDict)
    {
        PlayerRef player = kvp.Key;
        PlayerActionData actionData = kvp.Value;

        // 今日午前と今日午後が同じかチェック
        CheckConsecutivePenalty(player, actionData.AfternoonAction.ActionType, actionData.MorningAction.ActionType);

        // 行動を実行
        ExecuteAction(player, actionData.AfternoonAction, false);

        // 午後の行動を記録（次の日の午前判定用）
        actionData.LastAfternoonAction = actionData.AfternoonAction.ActionType;
    }
}
```

## 確認項目
- [ ] 1日目午前・午後で同じ行動を選択すると、午後実行時に元気が追加で20減少すること
- [ ] 1日目午後と2日目午前で同じ行動を選択すると、2日目午前実行時に元気が追加で20減少すること
- [ ] ログに「〇〇の連続使用ペナルティ！ 元気-20」と表示されること
- [ ] 異なる行動を選択した場合はペナルティが適用されないこと

## 注意点
- LastAfternoonActionはNetworkedプロパティで全クライアントに同期
- ペナルティは行動実行前に適用（元気が足りなくなる可能性あり）
- 連続判定は同じActionTypeかどうかで判定（Genreは無関係）
- 特殊能力も含めて連続使用判定を行う

## 連続使用の例

### 例1: 1日目午前・午後で同じ
- 1日目午前: たべる → 実行
- 1日目午後: たべる → ペナルティ適用後、実行

### 例2: 1日目午後と2日目午前で同じ
- 1日目午後: ねむる → 実行、LastAfternoonAction = Sleep に記録
- 2日目午前: ねむる → ペナルティ適用後、実行
