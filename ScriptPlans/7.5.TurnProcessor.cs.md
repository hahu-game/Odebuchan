# 7.5 TurnProcessor.cs (特殊能力: べんきょうの実装)

## ファイルパス
`Assets/Scripts/Game/TurnProcessor.cs`

## 目的
べんきょうの効果を実装する

## 実装概要
- ExecuteAction()にべんきょうの処理を追加
- 元気-25
- PlayBuffWeight +10
- StudyCombo +1、次回べんきょう時にPlayBuffWeight += (StudyCombo × 10)
- べんきょう以外の行動でStudyCombo = 0

## 確認項目
- [ ] べんきょう実行で元気-25、PlayBuffWeight+10されること
- [ ] 2回連続べんきょうで2回目はPlayBuffWeight+20されること
- [ ] べんきょう以外の行動でStudyComboがリセットされること
