# 6.4 GameFlowManager.cs (状態異常の効果適用 - 糖尿病)

## ファイルパス
`Assets/Scripts/Game/GameFlowManager.cs`

## 目的
準備フェーズでの糖尿病の朝処理を実装する

## 実装内容

### StartPreparationPhase()に糖尿病処理を追加

```csharp
/// <summary>
/// 準備フェーズ開始
/// </summary>
private async Task StartPreparationPhase()
{
    Debug.Log($"[GameFlowManager] {CurrentDay}日目の準備フェーズを開始します");

    CurrentPhase = GamePhase.Preparation;

    // ブラックアウトで「〇日目」を表示
    RPC_ShowBlackout($"{CurrentDay}日目");
    await Task.Delay((int)(gameParams.BlackoutDuration * 1000));

    // ログに日数を追加
    RPC_AddLog($"===== {CurrentDay}日目 =====");

    // 糖尿病チェック
    CheckDiabetes();

    // 進化判定（7.1で実装予定）
    // await CheckEvolution();

    // 選択フェーズへ遷移
    Debug.Log("[GameFlowManager] 準備フェーズ終了、選択フェーズへ遷移");
    await StartSelectionPhase();
}

/// <summary>
/// 糖尿病の朝処理
/// </summary>
private void CheckDiabetes()
{
    foreach (var kvp in GameManager.Instance.uyopyonStateDict)
    {
        UyopyonState uyopyon = kvp.Value;

        // 糖尿病を持っているかチェック
        if (HasStatusAilment(uyopyon, StatusAilment.Diabetes))
        {
            // 重さ-20、元気-20
            uyopyon.Weight -= gameParams.DiabetesPenaltyWeight;
            uyopyon.Energy -= gameParams.DiabetesPenaltyEnergy;

            RPC_AddLog(
                $"{uyopyon.OwnerPlayer}は糖尿病の影響を受けた！ 重さ-{gameParams.DiabetesPenaltyWeight}, 元気-{gameParams.DiabetesPenaltyEnergy}"
            );

            Debug.Log($"[GameFlowManager] {kvp.Key} 糖尿病の影響適用");
        }
    }
}

/// <summary>
/// 状態異常を持っているかチェック（TurnProcessorと同じヘルパーメソッド）
/// </summary>
private bool HasStatusAilment(UyopyonState uyopyon, StatusAilment ailment)
{
    for (int i = 0; i < uyopyon.StatusAilments.Length; i++)
    {
        if (uyopyon.StatusAilments[i] == (byte)ailment)
        {
            return true;
        }
    }
    return false;
}
```

## GameParametersへのパラメーター追加

```csharp
[Tooltip("糖尿病による朝の重さ減少")]
public int DiabetesPenaltyWeight = 20;

[Tooltip("糖尿病による朝の元気減少")]
public int DiabetesPenaltyEnergy = 20;
```

## Unityエディタでの設定

GameParametersアセットのInspectorで：
- Diabetes Penalty Weight: 20
- Diabetes Penalty Energy: 20

## 確認項目
- [ ] 糖尿病の状態で朝を迎えると、重さと元気が各20減少すること
- [ ] ログに「〇〇は糖尿病の影響を受けた！ 重さ-20, 元気-20」と表示されること
- [ ] 糖尿病がない状態では何も起きないこと
- [ ] 2人とも糖尿病の場合、両方に影響が適用されること

## 注意点
- 糖尿病の影響は準備フェーズ（朝）に適用
- 毎日朝に重さと元気が減少するため、治療しないと徐々に弱体化
- つういんで治療可能（状態異常をクリア）
- HasStatusAilment()ヘルパーメソッドはTurnProcessorと同じロジック

## 処理の流れ

1. **準備フェーズ開始**
2. ブラックアウト「〇日目」表示
3. **糖尿病チェック** ← ここで影響適用
4. 進化判定（7.1で実装）
5. 選択フェーズへ遷移

## 糖尿病の影響例

### 例: 1日目にたべるで糖尿病発症
- 1日目午前: たべる → 糖尿病発症
- **2日目朝**: 重さ-20、元気-20（糖尿病の影響）
- 2日目午前: 行動選択
- **3日目朝**: 重さ-20、元気-20（糖尿病の影響、まだ治療していない）
- 3日目午前: つういん → 糖尿病治癒
- **4日目朝**: 影響なし（糖尿病は治癒済み）
