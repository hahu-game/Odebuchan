# 4.3 UIController.cs (操作ロック機能の実装)

## ファイルパス
`Assets/Scripts/UI/UIController.cs`

## 目的
フェーズに応じてUIの操作可否を制御する

## 実装内容

### SetActionButtonsInteractable()メソッドの追加

```csharp
/// <summary>
/// 行動選択ボタンの操作可否を設定
/// </summary>
/// <param name="interactable">true: 操作可能, false: 操作不可</param>
public void SetActionButtonsInteractable(bool interactable)
{
    eatButton.interactable = interactable;
    sleepButton.interactable = interactable;
    playButton.interactable = interactable;
    clinicButton.interactable = interactable;
    fixButton.interactable = interactable;
    clearButton.interactable = interactable;

    Debug.Log($"[UIController] 行動ボタンの操作: {(interactable ? "可能" : "不可")}");
}
```

## GameFlowManagerからの呼び出し

GameFlowManager.csで以下のように呼び出します：

```csharp
// 選択フェーズ開始時
private async Task StartSelectionPhase()
{
    CurrentPhase = GamePhase.Selection;

    // UIの操作ロック解除
    RPC_SetActionButtonsInteractable(true);

    // ... 選択処理 ...

    // 選択フェーズ終了時
    RPC_SetActionButtonsInteractable(false);
}

// RPC
[Rpc(RpcSources.StateAuthority, RpcTargets.All)]
private void RPC_SetActionButtonsInteractable(bool interactable)
{
    UIController.Instance?.SetActionButtonsInteractable(interactable);
}
```

## 確認項目
- [ ] 準備フェーズでは行動選択ボタンがクリックできないこと（グレーアウト）
- [ ] 選択フェーズになるとクリックできるようになること（通常色）
- [ ] 実行フェーズでは再びクリックできなくなること（グレーアウト）
- [ ] 確定ボタンとクリアボタンも同様に制御されること

## 注意点
- Button.interactable プロパティを使用してボタンの有効/無効を切り替え
- interactable = false の場合、ボタンは自動的にグレーアウト表示される
- GameFlowManagerからRPCを使用して全クライアントに通知
- フェーズ遷移時に必ず呼び出されるようにする

## ボタンの視覚的フィードバック

Unityのボタンコンポーネントは、interactableプロパティに応じて自動的に以下の変化を行います：
- interactable = true: 通常の色で表示、クリック可能
- interactable = false: グレーアウトして表示、クリック不可

カスタムの色変更が必要な場合は、ButtonのInspectorで「Disabled Color」を設定できます。
