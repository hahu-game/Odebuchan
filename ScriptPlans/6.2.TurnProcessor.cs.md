# 6.2 TurnProcessor.cs (状態異常の発症処理 - ケガ)

## ファイルパス
`Assets/Scripts/Game/TurnProcessor.cs`

## 目的
あそぶ実行時のケガ発症判定を実装する

## 実装内容

### CheckInjury()メソッドの追加

```csharp
/// <summary>
/// ケガの発症判定（あそぶ実行時）
/// </summary>
/// <param name="player">プレイヤー</param>
/// <param name="weight">現在の重さ</param>
private void CheckInjury(PlayerRef player, int weight)
{
    var uyopyon = GameManager.Instance.GetUyopyonState(player);
    if (uyopyon == null) return;

    // 発症確率 = 現在の重さ ÷ 10 (%)
    float injuryChance = weight / 10f;
    float randomValue = Random.Range(0f, 100f);

    if (randomValue < injuryChance)
    {
        // ケガ発症
        bool hasBackPain = HasStatusAilment(uyopyon, StatusAilment.BackPain);
        bool hasHeatstroke = HasStatusAilment(uyopyon, StatusAilment.Heatstroke);

        StatusAilment newAilment;

        if (hasBackPain && hasHeatstroke)
        {
            // 両方すでに発症している場合は何もしない
            return;
        }
        else if (hasBackPain)
        {
            // 腰痛がある場合は熱中症を発症
            newAilment = StatusAilment.Heatstroke;
        }
        else if (hasHeatstroke)
        {
            // 熱中症がある場合は腰痛を発症
            newAilment = StatusAilment.BackPain;
        }
        else
        {
            // どちらもない場合は50%ずつで選択
            newAilment = Random.Range(0f, 1f) < 0.5f ? StatusAilment.BackPain : StatusAilment.Heatstroke;
        }

        // 状態異常を追加
        AddStatusAilment(uyopyon, newAilment);

        // ログに追加
        string ailmentName = GetStatusAilmentName(newAilment);
        GameFlowManager.Instance.RPC_AddLog($"{uyopyon.OwnerPlayer}は{ailmentName}になった！");

        Debug.Log($"[TurnProcessor] {player} {ailmentName}発症 (確率: {injuryChance}%, 判定値: {randomValue})");

        // 熱中症の場合は強制つういん処理（6.6で実装）
        // if (newAilment == StatusAilment.Heatstroke) { ... }
    }
}
```

### ExecuteAction()でのあそぶ実行時に呼び出し

```csharp
private void ExecuteAction(PlayerRef player, ActionData action, bool isMorning)
{
    var uyopyon = GameManager.Instance.GetUyopyonState(player);
    if (uyopyon == null) return;

    switch (action.ActionType)
    {
        case ActionType.Play:
            // あそぶの効果
            uyopyon.Energy -= 30;
            uyopyon.PlayBuffWeight += 10;
            uyopyon.PlayBuffEnergy += 10;

            // ケガ発症判定
            CheckInjury(player, uyopyon.Weight);
            break;

        // ... 他の行動 ...
    }
}
```

- [ ] 重さ100の場合、約10%の確率でケガが発症すること
- [ ] 発症した状態異常がログに表示されること
- [ ] すでに腰痛がある場合、2回目の発症で熱中症になること
- [ ] すでに熱中症がある場合、2回目の発症で腰痛になること
- [ ] 両方発症済みの場合、それ以上発症しないこと

## 注意点
- CheckInjury()の実装はCheckSickness()とほぼ同じ構造
- 病気とケガは別カテゴリだが、同じStatusAilments配列に格納
- 発症確率の計算式は病気と同じ（重さ÷10 = 発症確率%）
- 熱中症発症時の強制つういん処理は6.6で実装予定（この段階ではコメントアウト）
- UIへの表示は6.7で実装予定

## 病気とケガの違い

### 病気（たべるで発症）
- 睡眠時無呼吸症候群: ねむるの効果を減少
- 糖尿病: 朝に重さ-20、元気-20

### ケガ（あそぶで発症）
- 腰痛: 30%の確率で行動キャンセル
- 熱中症: 発症時に強制つういん（午後 or 翌日午前）
