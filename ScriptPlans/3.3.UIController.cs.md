# 3.3 UIController.cs (行動表示パネルの追加)

## ファイルパス
`Assets/Scripts/UI/UIController.cs`

## 目的
選択した行動と実行された行動を視覚的に表示する

## UI要素追加

### GameSceneに追加するUI要素
1. **MyYesterdayAfternoonActionPanel** - 自分の昨日午後の行動表示
2. **OppYesterdayAfternoonActionPanel** - 相手の昨日午後の行動表示
3. **MyTodayMorningActionPanel** - 自分の今日午前の行動表示（選択中）
4. **OppTodayMorningActionPanel** - 相手の今日午前の行動表示
5. **MyTodayAfternoonActionPanel** - 自分の今日午後の行動表示（選択中）
6. **OppTodayAfternoonActionPanel** - 相手の今日午後の行動表示

## コード追加箇所

```csharp
[Header("Action Display Panels")]
public GameObject myYesterdayAfternoonActionPanel;
public TextMeshProUGUI myYesterdayAfternoonActionText;
public GameObject oppYesterdayAfternoonActionPanel;
public TextMeshProUGUI oppYesterdayAfternoonActionText;

public GameObject myTodayMorningActionPanel;
public TextMeshProUGUI myTodayMorningActionText;
public Image myTodayMorningBorder; // 太枠表示用

public GameObject myTodayAfternoonActionPanel;
public TextMeshProUGUI myTodayAfternoonActionText;
public Image myTodayAfternoonBorder; // 太枠表示用

public GameObject oppTodayMorningActionPanel;
public TextMeshProUGUI oppTodayMorningActionText;

public GameObject oppTodayAfternoonActionPanel;
public TextMeshProUGUI oppTodayAfternoonActionText;

// 現在選択中の時間帯（午前 or 午後）
private bool isSelectingAfternoon = false;

/// <summary>
/// 行動表示を更新
/// </summary>
public void UpdateActionDisplay(PlayerRef player, bool isMorning, ActionType action)
{
    string actionText = GetActionText(action);

    // 自分のプレイヤーか判定
    bool isMyPlayer = IsMyPlayer(player);

    if (isMyPlayer)
    {
        if (isMorning)
        {
            myTodayMorningActionText.text = actionText;
        }
        else
        {
            myTodayAfternoonActionText.text = actionText;
        }
    }
    else
    {
        if (isMorning)
        {
            oppTodayMorningActionText.text = actionText;
        }
        else
        {
            oppTodayAfternoonActionText.text = actionText;
        }
    }
}

/// <summary>
/// 選択中の時間帯を太枠で表示
/// </summary>
public void HighlightCurrentSelection(bool isAfternoon)
{
    isSelectingAfternoon = isAfternoon;

    if (isAfternoon)
    {
        // 午後を選択中
        myTodayMorningBorder.color = Color.white;
        myTodayMorningBorder.GetComponent<Outline>().enabled = false;

        myTodayAfternoonBorder.color = Color.yellow;
        myTodayAfternoonBorder.GetComponent<Outline>().enabled = true;
    }
    else
    {
        // 午前を選択中
        myTodayMorningBorder.color = Color.yellow;
        myTodayMorningBorder.GetComponent<Outline>().enabled = true;

        myTodayAfternoonBorder.color = Color.white;
        myTodayAfternoonBorder.GetComponent<Outline>().enabled = false;
    }
}

/// <summary>
/// ActionTypeをテキストに変換
/// </summary>
private string GetActionText(ActionType action)
{
    switch (action)
    {
        case ActionType.Eat: return "たべる";
        case ActionType.Sleep: return "ねむる";
        case ActionType.Play: return "あそぶ";
        case ActionType.Clinic: return "つういん";
        case ActionType.SpecialAbility: return "特殊能力";
        default: return "";
    }
}

/// <summary>
/// 自分のプレイヤーかどうか判定
/// </summary>
private bool IsMyPlayer(PlayerRef player)
{
    // NetworkRunnerから自分のPlayerRefを取得して比較
    var runner = FindObjectOfType<NetworkRunner>();
    if (runner != null)
    {
        return runner.LocalPlayer == player;
    }
    return false;
}
```

## Unityエディタでの設定手順

1. GameSceneのCanvas内に行動表示パネルを作成
2. 各パネルにImage（背景）とTextMeshProUGUI（行動名）を配置
3. 今日午前・午後のパネルにはOutlineコンポーネントを追加（太枠表示用）
4. UIControllerのInspectorで各パネルとテキストの参照を設定
5. レイアウトを調整（画面中央付近に配置）

## 確認項目
- [ ] 午前の行動を選択するとMyTodayMorningActionPanelに表示されること
- [ ] 午後の行動を選択するとMyTodayAfternoonActionPanelに表示されること
- [ ] 選択中の時間帯のパネルが太枠（黄色）で表示されること
- [ ] 午前→午後と選択が進むと、太枠の位置が移動すること

## 注意点
- Outlineコンポーネントを使用して太枠を表現
- isSelectingAfternoonフラグで午前/午後の選択状態を管理
- 相手の行動は実行フェーズまで「？」などで隠す（後で実装）
