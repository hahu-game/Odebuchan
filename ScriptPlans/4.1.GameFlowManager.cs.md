## ファイルパス

## 目的
準備フェーズの処理を実装する

## 実装内容

### StartPreparationPhase()メソッドの拡張

```csharp
/// <summary>
/// 準備フェーズ開始
/// </summary>
private async Task StartPreparationPhase()
{
    Debug.Log($"[GameFlowManager] {CurrentDay}日目の準備フェーズを開始します");

    CurrentPhase = GamePhase.Preparation;

    // ブラックアウトで「〇日目」を表示
    RPC_ShowBlackout($"{CurrentDay}日目");

    // ブラックアウト表示時間待機
    await Task.Delay((int)(gameParams.BlackoutDuration * 1000));

    // ログに日数を追加
    RPC_AddLog($"===== {CurrentDay}日目 =====");

    // 糖尿病チェック（6.4で実装予定）
    // CheckDiabetes();

    // 進化判定（7.1で実装予定）
    // await CheckEvolution();

    // 選択フェーズへ遷移
    Debug.Log("[GameFlowManager] 準備フェーズ終了、選択フェーズへ遷移");
    await StartSelectionPhase();
}
```

## Unityエディタでの設定

特になし（既存のGameFlowManagerに追加するのみ）

- [ ] CurrentPhaseがPreparationになること

## 注意点
- この段階では糖尿病チェックと進化判定はコメントアウト（スタブ）
- 糖尿病チェックは6.4で実装
- 進化判定は7.1で実装
- ホスト（StateAuthority）のみがこのメソッドを実行
- RPCを使用して全クライアントにブラックアウトとログを表示

## 実装順序
1. この段階では基本的な準備フェーズの流れのみ実装
2. 後の段階で糖尿病チェックと進化判定を追加
3. 各日の始まりに必ず準備フェーズを通過する
