## 目的

## 実装内容

### StartExecutionPhase()メソッドの拡張

```csharp
/// <summary>
/// 実行フェーズ開始
/// </summary>
private async Task StartExecutionPhase()
{
    Debug.Log("[GameFlowManager] 実行フェーズを開始します");

    CurrentPhase = GamePhase.Execution;

    // ブラックアウト「行動開始！」を表示
    RPC_ShowBlackout("行動開始！");
    await Task.Delay((int)(gameParams.BlackoutDuration * 1000));

    // ログに実行フェーズ開始を追加
    RPC_AddLog("===== 行動実行 =====");

    // 相手の選択を表示（2秒待機）
    RPC_RevealOpponentActions();
    await Task.Delay(2000);

    // === 午前の行動実行 ===
    RPC_AddLog("--- 午前 ---");
    await Task.Delay(500);

    turnProcessor.ProcessMorning();
    await Task.Delay(2000); // アニメーション表示時間

    // 勝利判定（8.1で実装予定）
    // if (CheckVictory(out PlayerRef winner)) { ... }

    // === 午後の行動実行 ===
    RPC_AddLog("--- 午後 ---");
    await Task.Delay(500);

    turnProcessor.ProcessAfternoon();
    await Task.Delay(2000); // アニメーション表示時間

    // 勝利判定（8.1で実装予定）
    // if (CheckVictory(out PlayerRef winner)) { ... }

    // 次の日の準備フェーズへ遷移
    CurrentDay++;
    Debug.Log($"[GameFlowManager] {CurrentDay}日目へ移行します");
    await StartPreparationPhase();
}

/// <summary>
/// 相手の選択した行動を表示
/// </summary>
[Rpc(RpcSources.StateAuthority, RpcTargets.All)]
private void RPC_RevealOpponentActions()
{
    UIController.Instance?.RevealOpponentActions();
    Debug.Log("[RPC] 相手の選択を表示");
}
```

## UIController側の対応

UIController.csに以下のメソッドを追加：

```csharp
/// <summary>
/// 相手の選択した行動を表示
/// </summary>
public void RevealOpponentActions()
{
    // 相手のPlayerActionDataから行動を取得して表示
    // 実装は3.3で追加したUpdateActionDisplay()を使用

    foreach (var kvp in GameManager.Instance.playerActionDataDict)
    {
        if (!IsMyPlayer(kvp.Key))
        {
            // 相手の行動を表示
            UpdateActionDisplay(kvp.Key, true, kvp.Value.MorningAction.ActionType);
            UpdateActionDisplay(kvp.Key, false, kvp.Value.AfternoonAction.ActionType);
        }
    }
}
```

## 注意点
- 非同期処理（async/await）を使用して待機処理を実装
- Task.Delayでアニメーション表示時間を確保
- TurnProcessor.ProcessMorning()とProcessAfternoon()はホスト側で実行
- 勝利判定は8.1で実装予定（この段階ではコメントアウト）
- 相手の行動表示は選択フェーズでは隠し、実行フェーズ開始時に公開

## 実装順序
1. この段階では基本的な実行フェーズの流れのみ実装
2. 後の段階で勝利判定（8.1）を追加
3. アニメーション表示（10.1）も後で追加
