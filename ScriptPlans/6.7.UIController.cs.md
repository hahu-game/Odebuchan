# 6.7 UIController.cs (状態異常の表示)

## ファイルパス
`Assets/Scripts/UI/UIController.cs` および `Assets/Scripts/Data/UyopyonState.cs`

## 目的
状態異常をUIに表示する

## 実装内容

### 1. UIへの状態異常アイコン表示エリアの追加

GameSceneのMyStatusPanelとOppStatusPanelに以下を追加：
- StatusAilmentIconsPanel（水平レイアウト）
  - Icon1（Image）
  - Icon2（Image）
  - Icon3（Image）
  - Icon4（Image）

### 2. UIControllerへの参照追加

```csharp
[Header("Status Ailment Icons")]
public Image[] myStatusAilmentIcons = new Image[4];
public Image[] oppStatusAilmentIcons = new Image[4];

[Header("Status Ailment Sprites")]
public Sprite sleepApneaSprite;
public Sprite diabetesSprite;
public Sprite backPainSprite;
public Sprite heatstrokeSprite;
```

### 3. UpdateStatusAilmentDisplay()メソッドの実装

```csharp
/// <summary>
/// 状態異常アイコンを更新
/// </summary>
/// <param name="player">プレイヤー</param>
/// <param name="ailments">状態異常配列</param>
public void UpdateStatusAilmentDisplay(PlayerRef player, byte[] ailments)
{
    // 自分のプレイヤーか判定
    bool isMyPlayer = IsMyPlayer(player);
    Image[] icons = isMyPlayer ? myStatusAilmentIcons : oppStatusAilmentIcons;

    // すべてのアイコンを非表示
    foreach (var icon in icons)
    {
        icon.gameObject.SetActive(false);
    }

    // 状態異常があれば対応するアイコンを表示
    int iconIndex = 0;
    for (int i = 0; i < ailments.Length && iconIndex < icons.Length; i++)
    {
        if (ailments[i] != 0) // 状態異常あり
        {
            StatusAilment ailment = (StatusAilment)ailments[i];
            Sprite sprite = GetStatusAilmentSprite(ailment);

            if (sprite != null)
            {
                icons[iconIndex].sprite = sprite;
                icons[iconIndex].gameObject.SetActive(true);
                iconIndex++;
            }
        }
    }
}

/// <summary>
/// 状態異常に対応するスプライトを取得
/// </summary>
private Sprite GetStatusAilmentSprite(StatusAilment ailment)
{
    switch (ailment)
    {
        case StatusAilment.SleepApnea: return sleepApneaSprite;
        case StatusAilment.Diabetes: return diabetesSprite;
        case StatusAilment.BackPain: return backPainSprite;
        case StatusAilment.Heatstroke: return heatstrokeSprite;
        default: return null;
    }
}
```

### 4. UyopyonState.Render()から呼び出し

UyopyonState.csに以下を追加：

```csharp
// 状態異常の変更検知用
private byte[] _lastStatusAilments = new byte[4];

public override void Render()
{
    // ... 既存のコード ...

    // 状態異常の変更を検知
    bool ailmentsChanged = false;
    for (int i = 0; i < StatusAilments.Length; i++)
    {
        if (_lastStatusAilments[i] != StatusAilments[i])
        {
            ailmentsChanged = true;
            _lastStatusAilments[i] = StatusAilments[i];
        }
    }

    if (ailmentsChanged)
    {
        byte[] currentAilments = new byte[StatusAilments.Length];
        for (int i = 0; i < StatusAilments.Length; i++)
        {
            currentAilments[i] = StatusAilments[i];
        }
        UIController.Instance.UpdateStatusAilmentDisplay(OwnerPlayer, currentAilments);
    }
}
```

## アイコン画像の準備

以下のアイコン画像を用意してUnityにインポート：
- sleepApneaIcon.png（睡眠時無呼吸症候群）
- diabetesIcon.png（糖尿病）
- backPainIcon.png（腰痛）
- heatstrokeIcon.png（熱中症）

仮の画像がない場合は、Unity標準のスプライト（円や四角）に色をつけて代用可能。

## Unityエディタでの設定

1. MyStatusPanelとOppStatusPanelに「StatusAilmentIconsPanel」を追加
2. その下に4つのImage（Icon1～Icon4）を配置
3. UIControllerのInspectorで以下を設定：
   - My Status Ailment Icons: Icon1～Icon4の配列
   - Opp Status Ailment Icons: 相手用のIcon1～Icon4の配列
   - 各Sprite: 対応するアイコン画像
4. 初期状態ではすべてのアイコンを非表示（SetActive(false)）

## 確認項目
- [ ] 病気やケガが発症すると、対応するアイコンが表示されること
- [ ] つういんを実行すると、アイコンが消えること
- [ ] 両プレイヤーの状態異常が正しく表示されること
- [ ] 複数の状態異常がある場合、複数のアイコンが表示されること
- [ ] 最大4つまでアイコンが表示されること

## 注意点
- UyopyonState.Render()は全クライアントで毎フレーム実行される
- 状態異常の変更を検知してUIを更新（毎フレーム更新を避けるため）
- StatusAilmentsはNetworkArrayなので、Get()メソッドではなくインデックスアクセス
- アイコンは左から順に表示（発症順）

## 状態異常表示の例

### 例: 睡眠時無呼吸症候群のみ
- Icon1: 睡眠時無呼吸症候群アイコン（表示）

- Icon3～Icon4: 非表示

### 例: 全て発症

- Icon2: 糖尿病アイコン
- Icon3: 腰痛アイコン
