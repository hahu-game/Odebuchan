# 9.5 UIController.cs (うーぴょん画像のスケール変更)

## ファイルパス
`Assets/Scripts/UI/UIController.cs`

## 目的
重さに応じてうーぴょんの画像サイズを変更する

## 実装概要
- GameSceneにMyUyopyonImageとOppUyopyonImageを配置
- UpdateUyopyonScale(PlayerRef player, int weight)メソッドを実装:
  - 重さに応じてscaleを調整（例: 1kg = scale 1.0, 700kg = scale 3.0）
- UyopyonState.Render()から重さ変化時に呼び出す

## 確認項目
- [ ] たべるを実行すると、うーぴょんの画像が少し大きくなること
- [ ] 重さが700kgに近づくと、画像がかなり大きくなること
