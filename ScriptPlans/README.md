# ScriptPlans フォルダについて

このフォルダには、Odebuchanプロジェクトの段階的実装のための各スクリプトファイルの計画が含まれています。

## 概要

PROCESS.mdに記載された各段階に対応するスクリプトの実装内容を、mdファイルとして管理しています。これらのファイルは実際のcsファイルと混同しないよう、`.md`拡張子で作成されています。

## ファイル命名規則

```
<段階番号>.<サブ番号>.<スクリプト名>.cs.md
```

例:
- `1.1.GameEnums.cs.md` - フェーズ1、段階1.1の GameEnums.cs の実装計画
- `2.1.GameFlowManager.cs.md` - フェーズ2、段階2.1の GameFlowManager.cs の実装計画

## ファイル構成

各mdファイルには以下の内容が含まれています：

1. **ファイルパス**: 実際に作成するcsファイルのパス
2. **目的**: その段階で実装する機能の目的
3. **コード内容**: 実装するコードの全体または追加部分
4. **使用例**: コードの使い方の例（必要に応じて）
5. **確認項目**: 実装後に確認すべき動作
6. **注意点**: 実装時の注意事項

## 使い方

1. PROCESS.mdで現在の段階を確認
2. 対応するmdファイルを開く
3. mdファイルに記載されたコードを参考に、実際のcsファイルを作成または編集
4. 確認項目に従ってテストを実施
5. 次の段階に進む

## 注意事項

- これらのmdファイルはあくまで計画・参考資料であり、Unityプロジェクト上で実際に読み込まれることはありません
- 実装時には、mdファイルの内容をコピー＆ペーストして、適宜調整してください
- 実装の順序はPROCESS.mdに記載された順番に従ってください
