# 3.1 UIController.cs (GameSceneの基本UI配置)

## ファイルパス
`Assets/Scripts/UI/UIController.cs`

## 目的
行動選択ボタンとステータスパネルの基本レイアウトを作成する

## UI要素配置

### GameSceneに配置するUI要素
1. **Canvas** (Screen Space - Overlay)
2. **MyStatusPanel** (左上): プレイヤー名、重さ、元気
3. **OppStatusPanel** (右上): 相手の名前、重さ、元気
4. **ActionButtonsPanel** (中央下): 4つのボタン
   - たべるボタン
   - ねむるボタン
   - あそぶボタン
   - つういんボタン
5. **FixButton** (右下): 確定ボタン
6. **ClearButton** (左下): クリアボタン

## UIControllerへの参照追加

```csharp
using UnityEngine;
using UnityEngine.UI;
using TMPro;
using Fusion;

public class UIController : MonoBehaviour
{
    public static UIController Instance { get; private set; }

    [Header("Status Panels")]
    public GameObject myStatusPanel;
    public GameObject oppStatusPanel;
    public TextMeshProUGUI myPlayerNameText;
    public TextMeshProUGUI myWeightText;
    public TextMeshProUGUI myEnergyText;
    public TextMeshProUGUI oppPlayerNameText;
    public TextMeshProUGUI oppWeightText;
    public TextMeshProUGUI oppEnergyText;

    [Header("Action Buttons")]
    public Button eatButton;
    public Button sleepButton;
    public Button playButton;
    public Button clinicButton;

    [Header("Control Buttons")]
    public Button fixButton;
    public Button clearButton;

    private void Awake()
    {
        if (Instance != null && Instance != this)
        {
            Destroy(gameObject);
        }
        else
        {
            Instance = this;
        }
    }

    private void Start()
    {
        // ボタンのクリックイベントを設定
        eatButton.onClick.AddListener(() => OnActionButtonClicked(ActionType.Eat));
        sleepButton.onClick.AddListener(() => OnActionButtonClicked(ActionType.Sleep));
        playButton.onClick.AddListener(() => OnActionButtonClicked(ActionType.Play));
        clinicButton.onClick.AddListener(() => OnActionButtonClicked(ActionType.Clinic));
        fixButton.onClick.AddListener(OnFixButtonClicked);
        clearButton.onClick.AddListener(OnClearButtonClicked);
    }

    // 行動ボタンクリック時の処理（スタブ）
    private void OnActionButtonClicked(ActionType action)
    {
        Debug.Log($"行動ボタンがクリックされました: {action}");
        // 実装は3.2で行う
    }

    // 確定ボタンクリック時の処理（スタブ）
    private void OnFixButtonClicked()
    {
        Debug.Log("確定ボタンがクリックされました");
        // 実装は3.2で行う
    }

    // クリアボタンクリック時の処理（スタブ）
    private void OnClearButtonClicked()
    {
        Debug.Log("クリアボタンがクリックされました");
        // 実装は3.2で行う
    }

    // プレイヤー名を更新
    public void UpdatePlayerName(PlayerRef player, string playerName)
    {
        // 実装は既存のUIControllerにあり
    }

    // 重さを更新
    public void UpdateWeightDisplay(PlayerRef player, int weight)
    {
        // 実装は既存のUIControllerにあり
    }

    // 元気を更新
    public void UpdateEnergyDisplay(PlayerRef player, int energy)
    {
        // 実装は既存のUIControllerにあり
    }
}
```

## Unityエディタでの設定手順

1. GameSceneを開く
2. Canvasを作成（Screen Space - Overlay）
3. MyStatusPanelを作成（左上に配置）
   - 子要素: PlayerNameText, WeightText, EnergyText（TextMeshProUGUI）
4. OppStatusPanelを作成（右上に配置）
   - 子要素: PlayerNameText, WeightText, EnergyText（TextMeshProUGUI）
5. ActionButtonsPanelを作成（中央下に配置）
   - 子要素: EatButton, SleepButton, PlayButton, ClinicButton
6. FixButtonを作成（右下に配置）
7. ClearButtonを作成（左下に配置）
8. UIControllerスクリプトをCanvasにアタッチ
9. Inspectorで各UI要素の参照を設定
