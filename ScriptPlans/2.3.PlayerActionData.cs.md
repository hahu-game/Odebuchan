# 2.3 PlayerActionData.cs

## ファイルパス
`Assets/Scripts/Data/PlayerActionData.cs`

## 目的
プレイヤーの行動選択状態を管理するNetworkBehaviourを作成する

## コード内容

```csharp
using Fusion;
using UnityEngine;

/// <summary>
/// プレイヤーの行動選択データを管理するクラス
/// 各プレイヤーに1つずつスポーンされる
/// </summary>
public class PlayerActionData : NetworkBehaviour
{
    /// <summary>
    /// このデータの所有者
    /// </summary>
    [Networked]
    public PlayerRef OwnerPlayer { get; set; }

    /// <summary>
    /// 午前の行動
    /// </summary>
    [Networked]
    public ActionData MorningAction { get; set; }

    /// <summary>
    /// 午後の行動
    /// </summary>
    [Networked]
    public ActionData AfternoonAction { get; set; }

    /// <summary>
    /// 行動が確定されたか（確定ボタンが押されたか）
    /// </summary>
    [Networked]
    public bool IsActionFixed { get; set; } = false;

    /// <summary>
    /// 前日の午後の行動（連続使用ペナルティ判定用）
    /// </summary>
    [Networked]
    public ActionData LastAfternoonAction { get; set; }

    /// <summary>
    /// 午前の行動がロックされているか（熱中症による強制つういん）
    /// </summary>
    [Networked]
    public bool MorningActionLocked { get; set; } = false;

    /// <summary>
    /// 午後の行動がロックされているか（熱中症による強制つういん）
    /// </summary>
    [Networked]
    public bool AfternoonActionLocked { get; set; } = false;

    public override void Spawned()
    {
        // 初期値としてねむるを設定
        MorningAction = ActionData.Default();
        AfternoonAction = ActionData.Default();
        LastAfternoonAction = ActionData.Default();

        Debug.Log($"PlayerActionData spawned for Player {OwnerPlayer}");
    }

    /// <summary>
    /// 行動をリセット（新しい日の開始時に呼び出す）
    /// </summary>
    public void ResetForNewDay()
    {
        if (Object.HasStateAuthority)
        {
            // 前日の午後の行動を保存
            LastAfternoonAction = AfternoonAction;

            // 午前・午後をデフォルト（ねむる）にリセット
            MorningAction = ActionData.Default();
            AfternoonAction = ActionData.Default();

            // 確定フラグをリセット
            IsActionFixed = false;

            // ロックフラグをリセット（ただし、熱中症の場合は別途処理）
            // MorningActionLockedは熱中症処理で個別に設定されるのでここではリセットしない場合もある
            // AfternoonActionLockedは基本的にリセット
            AfternoonActionLocked = false;
        }
    }

    /// <summary>
    /// 午前の行動を設定（クライアント側からRPC経由で呼び出す）
    /// </summary>
    [Rpc(RpcSources.InputAuthority, RpcTargets.StateAuthority)]
    public void RPC_SetMorningAction(ActionData action)
    {
        if (!MorningActionLocked)
        {
            MorningAction = action;
            Debug.Log($"Player {OwnerPlayer} の午前の行動を設定: {action.Type}");
        }
        else
        {
            Debug.LogWarning($"Player {OwnerPlayer} の午前の行動はロックされています");
        }
    }

    /// <summary>
    /// 午後の行動を設定（クライアント側からRPC経由で呼び出す）
    /// </summary>
    [Rpc(RpcSources.InputAuthority, RpcTargets.StateAuthority)]
    public void RPC_SetAfternoonAction(ActionData action)
    {
        if (!AfternoonActionLocked)
        {
            AfternoonAction = action;
            Debug.Log($"Player {OwnerPlayer} の午後の行動を設定: {action.Type}");
        }
        else
        {
            Debug.LogWarning($"Player {OwnerPlayer} の午後の行動はロックされています");
        }
    }

    /// <summary>
    /// 行動を確定（クライアント側からRPC経由で呼び出す）
    /// </summary>
    [Rpc(RpcSources.InputAuthority, RpcTargets.StateAuthority)]
    public void RPC_FixActions()
    {
        IsActionFixed = true;
        Debug.Log($"Player {OwnerPlayer} の行動が確定されました");
    }

    /// <summary>
    /// 行動をクリア（クライアント側からRPC経由で呼び出す）
    /// </summary>
    [Rpc(RpcSources.InputAuthority, RpcTargets.StateAuthority)]
    public void RPC_ClearActions()
    {
        if (!MorningActionLocked)
        {
            MorningAction = ActionData.Default();
        }
        if (!AfternoonActionLocked)
        {
            AfternoonAction = ActionData.Default();
        }
        Debug.Log($"Player {OwnerPlayer} の行動がクリアされました");
    }
}
```

## GameManager.csへの追加内容

GameManagerに以下のコードを追加してPlayerActionDataをスポーンする：

```csharp
// GameManager.cs に追加

public NetworkObject playerActionDataPrefab; // Inspectorで設定

// プレイヤーIDとPlayerActionDataの対応
private Dictionary<PlayerRef, PlayerActionData> _playerActionData = new Dictionary<PlayerRef, PlayerActionData>();

/// <summary>
/// SpawnUyopyon()の中または後で、PlayerActionDataもスポーンする
/// </summary>
public void SpawnPlayerActionData(PlayerRef player)
{
    if (_playerActionData.ContainsKey(player)) return;

    NetworkObject newActionData = Runner.Spawn(
        playerActionDataPrefab,
        position: Vector3.zero,
        rotation: Quaternion.identity,
        inputAuthority: player
    );

    if (newActionData.TryGetBehaviour<PlayerActionData>(out var actionData))
    {
        actionData.OwnerPlayer = player;
        _playerActionData.Add(player, actionData);

        Debug.Log($"PlayerActionData spawned for Player {player}. Total: {_playerActionData.Count}");
    }
}

/// <summary>
/// 指定されたプレイヤーのPlayerActionDataを取得
/// </summary>
public PlayerActionData GetPlayerActionData(PlayerRef player)
{
    if (_playerActionData.ContainsKey(player))
    {
        return _playerActionData[player];
    }
    return null;
}

/// <summary>
/// 全プレイヤーのPlayerActionDataを取得
/// </summary>
public Dictionary<PlayerRef, PlayerActionData> GetAllPlayerActionData()
{
    return _playerActionData;
}
```

また、`SpawnUyopyon()`メソッドの最後に以下を追加：

```csharp
// SpawnUyopyon()の最後に追加
SpawnPlayerActionData(player);
```

## Prefab作成手順

1. Hierarchy に空の GameObject を作成し、名前を "PlayerActionData" にする
2. PlayerActionData スクリプトをアタッチ
3. NetworkObject コンポーネントをアタッチ
4. Project に Prefab として保存（Assets/Prefabs/PlayerActionData）
5. Hierarchy から削除
6. GameManager の Inspector で playerActionDataPrefab に設定

## 確認項目
- [ ] Unityエディタでコンパイルエラーが発生しないこと
- [ ] PlayerActionData Prefab が正しく作成されていること
- [ ] Play実行時に各プレイヤーに対してPlayerActionDataがスポーンされること
- [ ] RPC経由で行動が設定されること（Debug.Logで確認）

## 注意点
- InputAuthority（各プレイヤー）からRPC経由でホストに行動を送信
- ホスト（StateAuthority）がデータを管理
- ロックフラグは熱中症による強制つういん処理で使用
