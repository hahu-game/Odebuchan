# 3.4 UIController.cs (ブラックアウトパネルとログエリアの追加)

## ファイルパス
`Assets/Scripts/UI/UIController.cs`

## 目的
ゲーム進行状況を表示するUIを追加する

## UI要素追加

### GameSceneに追加するUI要素
1. **BlackoutPanel** - 全画面を覆う黒パネル + テキスト
   - Image（黒色、Alpha 0.8）
   - TextMeshProUGUI（中央に大きく表示）
2. **LogArea** - ScrollViewでログを表示
   - ScrollView
   - Content（ログメッセージを追加する親）
   - LogTextPrefab（ログ1行分のプレハブ）

## コード追加箇所

```csharp
using System.Collections;

[Header("Blackout Panel")]
public GameObject blackoutPanel;
public TextMeshProUGUI blackoutText;

[Header("Log Area")]
public ScrollRect logScrollRect;
public Transform logContent;
public GameObject logTextPrefab; // TextMeshProUGUIを持つプレハブ

/// <summary>
/// ブラックアウトパネルを表示
/// </summary>
/// <param name="text">表示するテキスト</param>
/// <param name="duration">表示時間（秒）</param>
public void ShowBlackout(string text, float duration)
{
    blackoutText.text = text;
    blackoutPanel.SetActive(true);

    // duration秒後に非表示
    StartCoroutine(HideBlackoutAfterDelay(duration));
}

/// <summary>
/// ブラックアウトパネルを非表示
/// </summary>
private IEnumerator HideBlackoutAfterDelay(float delay)
{
    yield return new WaitForSeconds(delay);
    blackoutPanel.SetActive(false);
}

/// <summary>
/// ログエリアにメッセージを追加
/// </summary>
/// <param name="message">ログメッセージ</param>
public void AddLog(string message)
{
    // ログテキストのプレハブをインスタンス化
    GameObject logObj = Instantiate(logTextPrefab, logContent);
    TextMeshProUGUI logText = logObj.GetComponent<TextMeshProUGUI>();

    if (logText != null)
    {
        // タイムスタンプ付きでログを表示
        string timestamp = System.DateTime.Now.ToString("HH:mm:ss");
        logText.text = $"[{timestamp}] {message}";
    }

    // 自動的に最下部にスクロール
    StartCoroutine(ScrollToBottom());
}

/// <summary>
/// ログエリアを最下部にスクロール
/// </summary>
private IEnumerator ScrollToBottom()
{
    // 1フレーム待ってからスクロール（レイアウト更新を待つため）
    yield return null;
    logScrollRect.verticalNormalizedPosition = 0f;
}

/// <summary>
/// ログをクリア
/// </summary>
public void ClearLog()
{
    foreach (Transform child in logContent)
    {
        Destroy(child.gameObject);
    }
}
```

## Unityエディタでの設定手順

### BlackoutPanelの作成
1. Canvas内に空のGameObjectを作成し、名前を "BlackoutPanel" にする
2. Imageコンポーネントを追加
   - Color: Black (R:0, G:0, B:0, A:200/255)
   - Anchor: Stretch（全画面）
3. 子要素としてTextMeshProUGUIを作成
   - 名前: "BlackoutText"
   - Font Size: 72
   - Alignment: Center Middle
   - Color: White
4. BlackoutPanelを最初は非表示（SetActive(false)）にしておく

### LogAreaの作成
1. Canvas内にScrollViewを作成し、名前を "LogArea" にする
2. Viewport > Content を設定
   - Content Size Fitter: Vertical Fit = Preferred Size
   - Vertical Layout Group を追加
3. LogTextPrefabを作成（Assets/Prefabsフォルダ）
   - TextMeshProUGUI
   - Font Size: 18
   - Color: White
   - Alignment: Left Top
4. UIControllerのInspectorで参照を設定
   - Blackout Panel: BlackoutPanel
   - Blackout Text: BlackoutText
   - Log Scroll Rect: LogArea (ScrollRect)
   - Log Content: LogArea/Viewport/Content
   - Log Text Prefab: LogTextPrefab

## 注意点
- ブラックアウトパネルはCanvas階層の最後に配置（最前面に表示）
- Coroutineを使用してブラックアウトの自動非表示を実装
- ログは無制限に追加されるため、必要に応じて古いログを削除する機能を追加することを検討
- GameFlowManager.RPC_ShowBlackout()とRPC_AddLog()から呼び出される
