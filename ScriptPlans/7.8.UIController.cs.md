# 7.8 UIController.cs (特殊能力ボタンと進化前表示の実装)

## ファイルパス
`Assets/Scripts/UI/UIController.cs`

## 目的
特殊能力に関するUIを完成させる

## 実装概要
- GameSceneにBeforeSpecialActionTextを追加（進化前のみ表示）
- GameSceneにSpecialActionButtonを追加（進化後のみ表示）
- UpdateSpecialAbilityDisplay(PlayerRef player, bool hasEvolved, string abilityName)メソッドを実装
- ShowBeforeEvolutionText(int currentWeight)メソッドを実装
- 進化前は「200kgで進化すると...」と表示
- 進化後は選択した特殊能力ボタンを表示

## 確認項目
- [ ] 重さ200kg未満でBeforeSpecialActionTextが表示されること
- [ ] 進化後、BeforeSpecialActionTextが非表示になりSpecialActionButtonが表示されること
- [ ] SpecialActionButtonをクリックすると選択した特殊能力が実行できること
