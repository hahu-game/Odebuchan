# 6.6 TurnProcessor.cs (状態異常の効果適用 - 熱中症)

## ファイルパス
`Assets/Scripts/Game/TurnProcessor.cs` および `Assets/Scripts/Data/PlayerActionData.cs`

## 目的
熱中症による強制つういん処理を実装する

## 実装内容

### 1. PlayerActionDataへのフラグ追加

PlayerActionData.csに以下を追加：

```csharp
/// <summary>
/// 午前の行動がロックされているか（熱中症による強制つういん）
/// </summary>
[Networked]
public bool MorningActionLocked { get; set; } = false;
```

### 2. CheckInjury()に熱中症の強制つういん処理を追加

```csharp
/// <summary>
/// ケガの発症判定（あそぶ実行時）
/// </summary>
private void CheckInjury(PlayerRef player, int weight, bool isMorning)
{
    // ... 既存の発症判定コード ...

    if (randomValue < injuryChance)
    {
        // ... 既存のケガ発症コード ...

        // 熱中症の場合は強制つういん処理
        if (newAilment == StatusAilment.Heatstroke)
        {
            HandleHeatstroke(player, isMorning);
        }
    }
}

/// <summary>
/// 熱中症発症時の強制つういん処理
/// </summary>
private void HandleHeatstroke(PlayerRef player, bool isMorning)
{
    var actionData = GameManager.Instance.GetPlayerActionData(player);
    if (actionData == null) return;

    if (isMorning)
    {
        // 午前に発症 → 今日の午後を「つういん」に強制変更
        actionData.AfternoonAction = new ActionData
        {
            ActionType = ActionType.Clinic,
            Genre = Genre.None
        };

        GameFlowManager.Instance.RPC_AddLog(
            $"熱中症のため、午後の行動が「つういん」に変更された"
        );
    }
    else
    {
        // 午後に発症 → 翌日の午前を「つういん」に固定
        actionData.MorningActionLocked = true;

        GameFlowManager.Instance.RPC_AddLog(
            $"熱中症のため、翌日午前の行動が「つういん」に固定された"
        );
    }
}
```

### 3. GameFlowManagerの準備フェーズで午前ロックをチェック

GameFlowManager.csのStartPreparationPhase()に追加：

```csharp
private async Task StartPreparationPhase()
{
    // ... 既存のコード ...

    // 熱中症による午前ロックチェック
    ApplyHeatstrokeMorningLock();

    // 糖尿病チェック
    CheckDiabetes();

    // ... 残りのコード ...
}

/// <summary>
/// 熱中症による午前ロックを適用
/// </summary>
private void ApplyHeatstrokeMorningLock()
{
    foreach (var kvp in GameManager.Instance.playerActionDataDict)
    {
        PlayerActionData actionData = kvp.Value;

        if (actionData.MorningActionLocked)
        {
            // 午前の行動を「つういん」に自動セット
            actionData.MorningAction = new ActionData
            {
                ActionType = ActionType.Clinic,
                Genre = Genre.None
            };

            // ロックを解除
            actionData.MorningActionLocked = false;

            RPC_AddLog($"{kvp.Key}の午前行動が自動的に「つついん」に設定された");
        }
    }
}
```

### 4. UIControllerで午前ロック状態を表示

UIController.csに以下を追加：

```csharp
/// <summary>
/// 午前ロック状態のボタンを制御
/// </summary>
public void UpdateMorningActionLock(bool isLocked)
{
    if (isLocked)
    {
        // 午前選択中の場合、ボタンを無効化
        eatButton.interactable = false;
        sleepButton.interactable = false;
        playButton.interactable = false;
        clinicButton.interactable = true; // つういんのみ有効

        // 視覚的にロックを表示
        myTodayMorningActionText.text = "つういん（固定）";
        myTodayMorningBorder.color = Color.red;
    }
}
```

- [ ] 午後にあそぶで熱中症が発症すると、翌日午前の行動が「つういん」に固定されること
- [ ] 固定された行動は変更できないこと（UIで表示）
- [ ] ログに強制つういんのメッセージが表示されること

## 注意点
- 熱中症は即座につういんを強制する特殊な状態異常
- 午前発症の場合は今日の午後、午後発症の場合は翌日午前に強制つういん
- MorningActionLockedフラグはNetworkedプロパティで全クライアントに同期
- つういんを実行すれば熱中症は治癒し、以降は通常通り行動できる

## 処理の流れ

### 午前に熱中症発症
1. 午前: あそぶ実行 → 熱中症発症
2. HandleHeatstroke(isMorning = true) → 午後の行動を「つういん」に変更
3. 午後: つういん実行 → 熱中症治癒

### 午後に熱中症発症
1. 午後: あそぶ実行 → 熱中症発症
2. HandleHeatstroke(isMorning = false) → MorningActionLocked = true
3. **翌日準備フェーズ**: ApplyHeatstrokeMorningLock() → 午前を「つついん」に自動セット
4. 午前: つういん実行 → 熱中症治癒
