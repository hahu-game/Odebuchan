# 7.1 GameFlowManager.cs (進化判定と特殊能力選択UIの実装)

## ファイルパス
`Assets/Scripts/Game/GameFlowManager.cs`

## 目的
重さ200kgで進化し、特殊能力を選択できるようにする

## 実装概要
- StartPreparationPhase()に進化判定を追加
- Weight >= 200 && !HasEvolvedの条件でCheckEvolution()を呼び出し
- AvailableSpecialAbilitiesから3つの選択肢を表示
- 選択完了まで待機し、UyopyonStateを更新（SpecialAbilityName, HasEvolved, VisualType）

## 確認項目
- [ ] 重さ200kg到達で準備フェーズに進化判定が実行されること
- [ ] SpecialActionChoicePanelが表示され3つの選択肢が表示されること
- [ ] 選択後、特殊能力が設定され進化フラグが立つこと
- [ ] 進化後は再度進化判定が行われないこと
