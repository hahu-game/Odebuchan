# 6.3 TurnProcessor.cs (状態異常の効果適用 - 睡眠時無呼吸症候群)

## ファイルパス
`Assets/Scripts/Game/TurnProcessor.cs`

## 目的
ねむる実行時の睡眠時無呼吸症候群の影響を実装する

## 実装内容

### ExecuteAction()のねむる処理を修正

```csharp
private void ExecuteAction(PlayerRef player, ActionData action, bool isMorning)
{
    var uyopyon = GameManager.Instance.GetUyopyonState(player);
    if (uyopyon == null) return;

    switch (action.ActionType)
    {
        case ActionType.Sleep:
            // ねむるの基本効果
            int energyRecovery = 50 + uyopyon.PlayBuffEnergy;

            // 睡眠時無呼吸症候群の影響をチェック
            if (HasStatusAilment(uyopyon, StatusAilment.SleepApnea))
            {
                energyRecovery -= gameParams.SleepApneaPenalty; // 20
                GameFlowManager.Instance.RPC_AddLog(
                    $"{uyopyon.OwnerPlayer}は睡眠時無呼吸症候群の影響を受けた！ 元気回復-{gameParams.SleepApneaPenalty}"
                );
            }

            uyopyon.Energy += energyRecovery;

            GameFlowManager.Instance.RPC_AddLog(
                $"{uyopyon.OwnerPlayer}はねむった。元気+{energyRecovery}"
            );
            break;

        // ... 他の行動 ...
    }
}
```

## GameParametersへのパラメーター追加

```csharp
[Header("Status Ailment Effects")]
[Tooltip("睡眠時無呼吸症候群による元気回復量減少")]
public int SleepApneaPenalty = 20;
```

## Unityエディタでの設定

GameParametersアセットのInspectorで：
- Sleep Apnea Penalty: 20

## 確認項目
- [ ] 睡眠時無呼吸症候群の状態でねむるを実行すると、元気回復量が30になること（50 - 20）
- [ ] ログに「〇〇は睡眠時無呼吸症候群の影響を受けた！ 元気回復-20」と表示されること
- [ ] 睡眠時無呼吸症候群がない状態では通常通り元気が50回復すること
- [ ] PlayBuffEnergyがある場合、それも含めて計算されること

## 注意点
- 睡眠時無呼吸症候群のペナルティは元気回復量の減少
- 最終的な元気回復量は (50 + PlayBuffEnergy - SleepApneaPenalty) になる
- 元気回復量がマイナスになる可能性もある（例: PlayBuffEnergy = 0 の場合、30回復）
- HasStatusAilment()ヘルパーメソッドは6.1で実装済み

## 計算例

### 通常時
- ねむる基本効果: +50
- PlayBuffEnergy: 0
- **合計: +50**

### 睡眠時無呼吸症候群あり
- ねむる基本効果: +50
- PlayBuffEnergy: 0
- 睡眠時無呼吸症候群ペナルティ: -20
- **合計: +30**

### PlayBuffあり + 睡眠時無呼吸症候群あり
- ねむる基本効果: +50
- PlayBuffEnergy: +20
- 睡眠時無呼吸症候群ペナルティ: -20
- **合計: +50**
