# 6.5 TurnProcessor.cs (状態異常の効果適用 - 腰痛)

## ファイルパス
`Assets/Scripts/Game/TurnProcessor.cs`

## 目的
腰痛による行動キャンセル処理を実装する

## 実装内容

### CheckBackPainCancellation()メソッドの追加

```csharp
/// <summary>
/// 腰痛による行動キャンセル判定
/// </summary>
/// <param name="player">プレイヤー</param>
/// <param name="action">行動データ（参照渡しで変更可能）</param>
/// <returns>キャンセルされた場合true</returns>
private bool CheckBackPainCancellation(PlayerRef player, ref ActionData action)
{
    var uyopyon = GameManager.Instance.GetUyopyonState(player);
    if (uyopyon == null) return false;

    // 腰痛を持っているかチェック
    if (HasStatusAilment(uyopyon, StatusAilment.BackPain))
    {
        // 30%の確率で行動キャンセル
        float randomValue = Random.Range(0f, 100f);
        if (randomValue < gameParams.BackPainCancelChance) // 30
        {
            // 行動を「ねむる」に変更
            action.ActionType = ActionType.Sleep;
            action.Genre = Genre.None;

            GameFlowManager.Instance.RPC_AddLog(
                $"{uyopyon.OwnerPlayer}は腰痛で動けない！ ねむるに変更"
            );

            Debug.Log($"[TurnProcessor] {player} 腰痛で行動キャンセル (確率: 30%, 判定値: {randomValue})");
            return true;
        }
    }
    return false;
}
```

### ExecuteAction()の呼び出し前にチェック

ProcessMorning()とProcessAfternoon()を修正：

```csharp
/// <summary>
/// 午前の行動を処理
/// </summary>
public void ProcessMorning()
{
    foreach (var kvp in GameManager.Instance.playerActionDataDict)
    {
        PlayerRef player = kvp.Key;
        PlayerActionData actionData = kvp.Value;
        ActionData morningAction = actionData.MorningAction;

        // 腰痛による行動キャンセルチェック
        CheckBackPainCancellation(player, ref morningAction);

        // 連続使用ペナルティチェック
        CheckConsecutivePenalty(player, morningAction.ActionType, actionData.LastAfternoonAction);

        // 行動を実行
        ExecuteAction(player, morningAction, true);
    }
}

/// <summary>
/// 午後の行動を処理
/// </summary>
public void ProcessAfternoon()
{
    foreach (var kvp in GameManager.Instance.playerActionDataDict)
    {
        PlayerRef player = kvp.Key;
        PlayerActionData actionData = kvp.Value;
        ActionData afternoonAction = actionData.AfternoonAction;

        // 腰痛による行動キャンセルチェック
        CheckBackPainCancellation(player, ref afternoonAction);

        // 連続使用ペナルティチェック
        CheckConsecutivePenalty(player, afternoonAction.ActionType, actionData.MorningAction.ActionType);

        // 行動を実行
        ExecuteAction(player, afternoonAction, false);

        // 午後の行動を記録（次の日の午前判定用）
        actionData.LastAfternoonAction = afternoonAction.ActionType;
    }
}
```

## 確認項目
- [ ] 腰痛の状態で行動を選択すると、30%の確率でねむるに変更されること
- [ ] ログに「〇〇は腰痛で動けない！ ねむるに変更」と表示されること
- [ ] キャンセルされなかった場合は選択した行動が実行されること
- [ ] 腰痛がない状態では行動がキャンセルされないこと

## 注意点
- 腰痛チェックは行動実行前に行う（連続使用ペナルティの前）
- ActionDataは構造体なので、ref キーワードで参照渡しして変更
- キャンセルされた場合、元の行動は失われ「ねむる」になる
- つういんで腰痛を治療すれば、以降キャンセルされなくなる

## 処理の流れ

1. **腰痛チェック** ← ここで30%の確率でねむるに変更
2. 連続使用ペナルティチェック
3. 行動実行

## 腰痛キャンセルの例

### 例: 腰痛でたべるがキャンセル
- 午前の行動: たべる（選択）
- 腰痛チェック: 30%の確率でキャンセル → ねむるに変更
- 実行: ねむる（たべるではなく）
- ログ: 「〇〇は腰痛で動けない！ ねむるに変更」「〇〇はねむった。元気+50」
